# Car Service AI Monorepo
Created by: **Toni Jukka**

This repository contains the full source code for the global Car Service AI Operating System.

## Architecture Overview
- AI Platform (LLM agents, RAG, Vision AI, Acoustic AI)
- Workshop Applications (mobile + web)
- Admin Dashboard
- Customer Portal
- Partner API
- Microservices (diagnostics, pricing, inventory, payments, compliance)
- Data Platform (warehouse, ETL, analytics)
- Security & Compliance (GDPR, SERMI, ISO27001)
- Multi-tenant SaaS Core
